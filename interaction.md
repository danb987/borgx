# Interaction Design - AI & Metallurgy Consulting Website

## Core User Interactions

### 1. Book a Call CTA
- **Primary Action**: Prominent "Book a call with us" button in hero section
- **Behavior**: Opens contact form overlay with fields for:
  - Name
  - Company
  - Email
  - Phone
  - Service interest (dropdown: Data Audit, Synthetic Data, Education/Coaching)
  - Message
- **Validation**: Real-time form validation with success/error states

### 2. Service Exploration
- **Navigation**: Smooth scroll to service sections
- **Service Cards**: Interactive hover effects revealing detailed descriptions
- **Filter System**: Toggle between service categories (Data Audit, Synthetic Data, Education)

### 3. Client Type Selector
- **Interactive Grid**: 4 client type cards with hover animations
- **Types**:
  - Steel & Metal Producers
  - Mining Companies
  - Manufacturing Plants
  - R&D Institutions
- **Behavior**: Click reveals case study preview and relevant services

### 4. Insights Section
- **Article Cards**: Blog-style layout with category filters
- **Search Function**: Real-time search through insights/articles
- **Tags**: Clickable tags for filtering content by topic

### 5. Contact Integration
- **Multi-channel**: Phone, email, LinkedIn integration
- **Location Map**: Interactive map showing office location
- **Response Time**: Display expected response time indicators

## User Journey Flow
1. Land on hero → Impressed by industrial imagery and clear value prop
2. Explore "Who We Help" → Identify with client type
3. Navigate to services → Understand offerings
4. Read insights → Build credibility
5. Book call → Convert to lead

## Interactive Elements
- Smooth scrolling navigation
- Hover effects on all clickable elements
- Loading animations for form submissions
- Progress indicators for multi-step processes
- Mobile-responsive touch interactions
